# 문제 해결과 버그 제보

[README로 돌아가기](../README.md) · [설치 가이드](INSTALLATION.md)

## 먼저 확인해 주세요

| 증상 | 확인할 내용 |
|---|---|
| 실행했는데 창이 없습니다 | 메뉴바 전용 앱입니다. 화면 위쪽 마우스 아이콘·잔량 표시를 확인합니다. |
| ‘그래도 열기’가 보이지 않습니다 | 응용 프로그램 폴더의 앱을 한 번 실행해 차단 메시지를 확인한 뒤 시스템 설정을 다시 확인합니다. 관리되는 Mac이면 관리자에게 문의합니다. |
| 리시버가 연결되지 않았다고 나옵니다 | Bluetooth 직접 연결이 아닌 Logi Bolt 리시버 연결인지 확인합니다. USB 허브·액세서리 허용 상태도 확인합니다. |
| 장치를 찾지 못하거나 ‘응답 없음’이 나옵니다 | 마우스 전원, 리시버와 연결된 Easy-Switch 채널을 확인하고 마우스를 움직인 뒤 ‘지금 갱신’을 선택합니다. Options+ 설치는 필수가 아닙니다. |
| 알림이 오지 않습니다 | 앱의 알림 기준과 **시스템 설정 → 알림 → Bolt Battery**, 집중 모드 설정을 확인합니다. 충전 중에는 보내지 않으며, 한 번 알린 뒤에는 충전 감지 또는 기준보다 5%p 이상 회복해야 다시 알립니다. |

## 버그 제보

문제가 계속되면 진단 정보를 복사해 [새 이슈](https://github.com/heonny/BoltBattery/issues/new)에 첨부해 주세요.

1. 메뉴바의 Bolt Battery를 열고 오른쪽 위 **톱니바퀴 → 진단 → 진단 정보 복사**를 선택합니다.
2. 복사한 내용을 확인한 뒤 이슈 본문에 붙여 넣습니다. 앱·macOS 버전, 연결·배터리 상태와 설정이 포함됩니다.
3. **마우스 모델, 재현 순서, 기대한 동작, 실제 동작**을 적습니다. 진단 정보에는 장치 이름이 없으므로 모델을 별도로 알려 주세요.
4. 화면 문제라면 개인정보가 보이지 않도록 확인한 스크린샷도 첨부합니다.

앱을 실행할 수 없어 진단 정보를 복사하지 못해도 이슈를 등록할 수 있습니다. 다운로드한 앱 버전, macOS 버전, Mac의 칩 종류, 표시된 오류를 알려 주세요.

### 상세 로그가 필요한 경우

진단 파일 로그는 기본으로 꺼져 있습니다. 문제 재현 과정을 남기거나 추가 로그를 요청받은 경우에만 사용합니다.

1. **진단 → 진단 로그 쓰기**를 켭니다.
2. 문제를 재현합니다.
3. **진단 → 로그 폴더 열기…**에서 로그 파일을 확인합니다.
4. **진단 로그 쓰기**를 다시 끕니다. 기존 파일은 자동으로 삭제되지 않습니다.
5. 필요한 구간만 첨부합니다. 원본 로그에는 장치 이름·식별 정보·파일 경로가 포함될 수 있으므로 공개 전 확인해 주세요.

기록이나 차트 문제라면 **진단 → 배터리 기록 내보내기…**로 CSV를 저장해 필요한 부분을 첨부할 수 있습니다. 시간 정보가 사용 패턴을 드러낼 수 있으므로 전체 파일을 반드시 첨부할 필요는 없습니다.

진단 복사·로그 저장·CSV 내보내기는 이슈를 자동 등록하거나 파일을 업로드하지 않습니다. 수집 항목과 공유 시 주의사항은 [권한과 저장 데이터](DATA-AND-PERMISSIONS.md#진단-정보-공유)를 참고해 주세요.
