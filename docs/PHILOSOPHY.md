# Bolt Battery Philosophy

Bolt Battery는 마우스 배터리를 조용히 알려주는 작은 macOS 도구다. 빠르게 읽히는 표시, 시스템과의 조화, 낮은 자원 사용을 우선한다.

## 작고 명확하게

메뉴바에서는 마우스 아이콘과 잔량 숫자만으로 상태를 알 수 있어야 한다. 아이콘은 장치의 종류를, 숫자는 정확한 잔량을 맡는다. 배터리 수위 채움이나 장식적인 내부 선으로 같은 정보를 중복 표현하지 않는다.

기본 표시는 아이콘과 퍼센트이며, 설정에서 퍼센트만 또는 아이콘만 선택할 수 있다. 설정은 상단 오른쪽 시스템 메뉴에 모으고, 세 표시 방식 중 하나만 체크한다. 앱 정보는 메뉴 맨 아래 종료 바로 위에 둔다.

차트 헤더 첫 줄은 장치 이름과 `gearshape` 설정 버튼을 정렬하고, 둘째 줄에 잔량과 마지막 확인 시각을 함께 표시한다. 설정 버튼은 배경 없이 28×28 클릭 영역을 유지한다.

갱신과 배터리 기록 초기화도 설정 메뉴에 모아 차트 아래 버튼 줄을 두지 않는다. 초기화는 시스템 확인 창에서 삭제 대상을 알리고 승인받는다. 설정 목록은 메뉴바의 배터리 아이콘 아래에 고정해서 연다. 차트 메뉴를 먼저 닫으며, 패널 안 버튼이나 마우스 위치를 기준으로 배치하지 않는다.

현재 형태는 앞이 평평하고 뒤가 둥근 custom solid 몸통에 휠 홈 하나다. MX Master의 실제 윤곽이나 브랜드 개성을 억지로 재현하지 않는다. 기본 심볼이라는 이유만으로 채택하지 않고, 실제 메뉴바에서 더 잘 읽히는 형태를 선택한다. 세부 좌표는 코드에서 관리한다.

앱 아이콘은 과한 반사를 줄인 옅은 반투명 바탕과 MX Master의 비대칭 윤곽, 초록 번개가 있는 작은 Bolt USB 리시버를 사용한다. 마우스와 리시버는 사실적인 제품 렌더링 대신 간결한 면 중심의 그래픽으로 표현한다. 정보 창과 Finder용 정적 자산이며, 메뉴바 아이콘과 상태별 색상 규칙은 그대로 유지한다. 원본은 `Packaging/AppIcon.png`, 크기별 macOS 아이콘은 빌드할 때 생성한다.

## macOS와 조화롭게

메뉴와 상호작용은 시스템이 제공하는 동작과 표현을 우선한다. 아이콘의 기본색은 템플릿 이미지로 두어 어두운 메뉴바에서는 흰색, 밝은 메뉴바에서는 검정으로 표시한다.

색상은 임의 RGB 대신 AppKit의 동적 시스템 색상을 사용한다. 이는 macOS 기본 색상 팔레트를 따른다는 뜻이며, 배터리 메뉴바 내부의 전용 색상을 복제한다는 뜻은 아니다.

| 상태 | 표시 |
|---|---|
| 충전 중 | `NSColor.systemGreen` — 잔량보다 우선 |
| 0~9% | `NSColor.systemRed` |
| 10~29% | `NSColor.systemYellow` |
| 30~100% | 템플릿 흑백 |
| 응답 없음 | 마지막 상태의 아이콘을 50% 알파로 표시. 통신 실패만으로 절전을 단정하지 않는다. |
| 장치 없음 | 템플릿 아이콘을 50% 알파로 표시하고 숫자는 `--` |

잔량 경계값은 이 앱의 규칙이다. 색이 달라져도 아이콘의 형태는 유지한다.

## 가볍고 단순하게

메뉴바의 작은 정적 AppKit 벡터로 충분한 표현에 외부 라이브러리, 이미지 자산, 애니메이션을 추가하지 않는다. 아이콘을 위해 별도 타이머나 폴링을 만들지 않는다.

성능 문제가 측정되기 전에는 캐시나 복잡한 렌더링 계층을 추가하지 않는다. 자원 사용이 걱정되면 먼저 측정하고, 실제로 비용이 큰 부분만 개선한다. 디버그 미리보기 생성은 평상시 실행 경로에 포함하지 않는다.

진단 파일은 고빈도 입력 대신 연결·조회·오류를 기록한다. 파일 쓰기는 백그라운드 직렬 큐에서 처리하고 용량을 제한한다. 기본값은 꺼짐이며, 필요할 때 설정 메뉴의 ‘진단 로그 쓰기’를 켠다. 사용자의 선택은 재실행 후에도 유지하며, 이를 위해 별도 타이머를 두지 않는다.

장치 통신과 아이콘 표현은 분리한다. 시각 변경을 위해 HID나 배터리 모델의 동작을 바꾸지 않는다. 장치 접근의 안전 제약은 [CLAUDE.md](../CLAUDE.md)를 따른다.

## 실제 사용 크기로 판단하기

확대본의 정교함보다 실제 메뉴바에서의 식별성, 형태 균형, 주변 아이콘과의 무게감, 잔량별 일관성을 본다. 자체 점수는 비교 도구일 뿐 사용자의 만족을 대신하지 않는다.

시각 변경마다 새 빌드를 만들고 기존 앱을 종료한 뒤 재실행한다. 실행된 메뉴바를 직접 캡처하여 확인한다. 밝고 어두운 배경, 색상 경계값, 충전, 절전, 장치 없음은 디버그 미리보기로 함께 확인한다.

```sh
scripts/make-app.sh debug
# 기존 앱 종료 후 새 번들 실행
open .build/BoltBattery.app

# 별도 디버그 실행으로 상태별 미리보기 생성
BOLT_DEBUG_ICON=/tmp/bolt-icons.png .build/debug/BoltBattery
```

## 이 문서의 유지 원칙

제품과 디자인 원칙은 이 문서 한 곳에서 관리한다. 합의된 원칙이나 상태 규칙이 바뀌면 코드 변경과 함께 갱신한다. 폐기한 시안, 작업 중 점수, 대화 이력은 누적하지 않는다. 실행과 빌드 안내는 [README.md](../README.md), 개발 제약과 구조는 [CLAUDE.md](../CLAUDE.md)에 두며 원칙을 중복 작성하지 않는다. 완료한 계획은 Git 이력으로 남긴다.
