# 설치 가이드

[README로 돌아가기](../README.md)

## DMG로 설치

macOS 13 이상에서 사용할 수 있습니다. Intel과 Apple Silicon 모두 같은 DMG를 사용하며, 실행에는 Xcode나 별도 라이브러리가 필요하지 않습니다.

1. 이 저장소의 [Releases](https://github.com/heonny/BoltBattery/releases)에서 `BoltBattery-버전.dmg`를 받습니다. `Source code` 압축 파일은 설치 파일이 아닙니다.
2. DMG를 열고 `BoltBattery.app`을 `Applications` 폴더로 옮깁니다.
3. 기존 앱이 실행 중이면 종료한 뒤, 응용 프로그램 폴더의 앱을 실행합니다.
4. 설치용 디스크를 추출합니다. 이후에는 DMG 안의 앱이 아닌 응용 프로그램 폴더의 앱을 실행합니다.

앱은 Dock 아이콘이나 일반 창 없이 **화면 위쪽 메뉴바**에 표시됩니다. 마우스 아이콘 또는 배터리 숫자를 클릭하면 차트가 열리고, 차트 오른쪽 위 톱니바퀴에서 설정을 엽니다.

기본 릴리즈 스크립트는 ad-hoc 서명을 사용하며 Apple 공증을 포함하지 않습니다. 다운로드한 앱이 개발자 확인 또는 공증 문제로 차단되면, 출처를 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 해당 앱의 실행을 허용할 수 있습니다. 이는 [장치 접근·알림 권한](DATA-AND-PERMISSIONS.md#권한과-시스템-접근)과 별개입니다. [Apple의 앱 실행 안내](https://support.apple.com/ko-kr/102445)를 참고해 주세요.

Gatekeeper 전체 비활성화나 격리 속성 일괄 제거는 설치 절차에 포함하지 않습니다. 악성 소프트웨어·앱 손상 경고가 나타나면 강제로 실행하지 말고 다운로드 출처와 파일을 확인해 주세요. 관리되는 Mac에서는 조직 정책에 따라 실행 허용이 제한될 수 있습니다.

## 처음 실행한 뒤

1. Logi Bolt USB 리시버를 연결합니다. 현재 버전은 **Bluetooth 직접 연결을 지원하지 않습니다.** 마우스가 이 리시버에 페어링되어 있어야 합니다. macOS가 액세서리 연결을 물으면 연결한 리시버인지 확인하고 허용합니다.
2. 마우스를 켜고 움직인 뒤 메뉴바의 Bolt Battery를 엽니다. 잔량이 아직 없으면 설정의 ‘지금 갱신’을 선택합니다. 장치를 찾지 못한 동안에는 약 30초 간격으로 재탐색합니다.
3. ‘입력 모니터링 권한 허용…’이 표시될 때만 버튼을 누르고 시스템 설정에서 Bolt Battery를 허용합니다. 돌아와 ‘다시 시도’를 선택하고, macOS가 앱 재실행을 요구하면 종료 후 다시 실행합니다. 이 안내가 없으면 권한을 미리 켤 필요가 없습니다.
4. 원하는 경우 ‘로그인 시 실행’을 켭니다. 추가 승인 안내가 나오면 **시스템 설정 → 일반 → 로그인 항목**에서 허용합니다. macOS 버전에 따라 항목 이름이 다를 수 있습니다.
5. 배터리 부족 알림이 필요하면 기준을 선택하고 시스템 알림 요청을 허용합니다. 알림과 진단 파일 로그는 기본으로 꺼져 있습니다.

처음에는 기록이 없어 차트가 비어 있을 수 있습니다. 서로 다른 10분 구간의 기록이 두 개 이상 쌓이면 그래프가 표시됩니다. 앱이 종료된 동안의 기록은 수집하지 않습니다.

문제가 생기면 [문제 해결과 버그 제보](SUPPORT.md)를 참고해 주세요.

## 다운로드 검증

다운로드 파일을 검증하려면 DMG와 같은 릴리즈의 `SHA256SUMS.txt`를 같은 폴더에 저장한 뒤, 터미널에서 해당 폴더로 이동하여 실행합니다. 파일 이름을 바꾸지 않은 경우 `OK`로 표시되어야 합니다.

```sh
shasum -a 256 -c SHA256SUMS.txt
```

체크섬은 다운로드 파일의 일치 여부를 확인하는 용도이며, Developer ID 서명이나 Apple 공증을 대신하지 않습니다.

## 소스에서 빌드

Swift 6을 지원하는 Xcode가 필요합니다. 외부 패키지 설치는 필요하지 않습니다.

```sh
git clone https://github.com/heonny/BoltBattery.git
cd BoltBattery
scripts/release.sh
cp -R .build/BoltBattery.app /Applications/
open /Applications/BoltBattery.app
```

기존 앱이 실행 중이라면 종료한 뒤 설치합니다. 빌드 결과로 유니버설 앱과 DMG가 생성됩니다. 기본 빌드는 ad-hoc 서명을 사용하며 Apple 공증은 포함하지 않습니다.

배포자는 `SIGN_IDENTITY`에 Developer ID Application 인증서를, `NOTARY_PROFILE`에 미리 등록한 `notarytool` 키체인 프로필을 지정해 `scripts/release.sh`에서 서명·공증·티켓 첨부를 수행할 수 있습니다. CI의 서명 검증 통과가 Apple 공증 완료를 뜻하지는 않습니다.
